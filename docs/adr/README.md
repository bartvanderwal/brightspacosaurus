# Architecture Decision Records

This directory contains the English ADR collection for Brightspacosaurus.

The numbering is historical rather than contiguous. Brightspacosaurus was extracted and generalized from an original course-material repository; decisions belonging only to that course or removed during the extraction are not part of this repository. Earlier reconstructed release context is recorded in [CHANGELOG.md](../../CHANGELOG.md).
