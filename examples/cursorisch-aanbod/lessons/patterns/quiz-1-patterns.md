# Quiz 1: Agentic UI patterns

## Opdracht 1

An agent in a file manager is asked to archive twelve old invoices.

### Deelvraag 1a (2 pt)

What should the agent do first?

- A. Move the files and report afterwards
- B. Show a dry run that lists the twelve files without moving them
- C. Ask "Do you approve?" before showing anything
- D. Stream the file names while moving them

Correct answer: **B**

### Deelvraag 1b (3 pt)

Why should an approval come after the dry run?

- A. It makes the screen look busier
- B. The user can judge a concrete result first
- C. It speeds up the agent a little
- D. It replaces the cancel button

Correct answer: **B**
