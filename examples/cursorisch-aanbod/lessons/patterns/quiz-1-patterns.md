# Quiz 1: Agentic UI patterns

## Opdracht 1

An agent in a mail app wants to send a reply to a customer.

### Deelvraag 1a (2 pt)

Which pattern fits best before the agent sends the reply?

- A. Streaming text
- B. Human in the loop
- C. Step list
- D. No pattern is needed

Correct answer: **B**

### Deelvraag 1b (3 pt)

Why should an approval step show a preview of the result?

- A. It makes the screen look busier
- B. The user can judge the result first
- C. It speeds up the agent a little
- D. It replaces the cancel button

Correct answer: **B**
