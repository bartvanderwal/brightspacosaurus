# About this course

*Intro to Agentic UI patterns* is a short, fictional course. It exists to show how BSO builds a Brightspace menu from topic folders instead of weeks.

## How to work through it

1. Read the introduction.
2. Study the patterns and make the quiz.
3. Use the evaluation checklist on an agentic UI you know.
4. Keep the glossary reader at hand.
