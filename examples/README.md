# Voorbeeldconfiguraties

Deze map bevat voorbeelden van `brightspacosaurus.config.json` voor verschillende cursusprojecten.

## Gebruik

Kopieer het relevante voorbeeld naar de root van je cursusproject en pas het aan:

```sh
cp examples/owe-1.config.json /pad/naar/cursusproject/brightspacosaurus.config.json
```

## Bestanden

| Bestand | Cursus | Beschrijving |
|---------|--------|-------------|
| `owe-1.config.json` | OWE-1 Full Stack Engineering | Volledige configuratie met readers en docentenhandleiding |
| `oose-dt-sad.config.json` | OOSE-DT Software Analysis & Design | Minimale configuratie (alleen lespagina's) |
