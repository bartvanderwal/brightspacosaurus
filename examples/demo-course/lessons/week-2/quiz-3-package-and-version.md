# Quiz 2.3: Package and Version

## Question 1

Where does the BSO package version come from?

- A. `deno.json`
- B. The lesson title
- C. The reader filename
- D. The quiz answer

Correct answer: **A**

- A. HTML, QTI, readers, images and the manifest
- B. Only the Markdown source of the lessons
- C. Only the Java source of the assignments
