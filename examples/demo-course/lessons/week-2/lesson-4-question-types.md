# Lesson 2.4: Question types and code in quizzes

This lesson shows the Quizzosaurus quiz syntax in a `quiz` fenced block. Quiz 2.4 uses it for three question types:

- single choice with `( )` and `(x)`
- multiple response with `[ ]` and `[x]`
- open short answer with `=` and accepted answers separated by `/`

The quiz also has inline code and fenced Java and JSX code in the questions, the options and the hints. In the Brightspace export they become `<code>` and `<pre>` blocks, and characters such as `<` and `&` stay readable.
