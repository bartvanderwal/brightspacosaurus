## Version information

After a new Brightspace import, check here that you imported the current version.

{@bso-versions}

BSO fills in the table above during the build (`teacherPage` in `brightspacosaurus.config.json`, default `for-teachers.md`).

{@bso-teacher-dashboard}

When `teacherDashboard` is configured, the directive above turns this page into two tabs: this information and the Voortgangsverkenner. The repository's demo configuration uses a fictitious GitLab server; replace those placeholders with your own settings before fetching data. Projects created with `bso init` omit this optional configuration.
