# Lesson 2: Test Pyramid and Test Strategy

{@include: [Learning goals](../../partials/learning-goals.md)}

A test strategy chooses appropriate tests for different levels of a system.

## Test pyramid

```text
        /\
       /E2E\
      /------\
     /Integr. \
    /----------\
   / Unit tests \
  /--------------\
```

The test pyramid combines many fast unit tests with fewer, more expensive integration and end-to-end tests.
